# Changelog

All notable user-facing changes to Umbrella Problems are recorded here.

## [1.0.0] - 2026-07-19

### Added

- Responsive, interactive SVG rainy scene with Milo, an umbrella, clouds, wind, puddles, and a bird.
- Ten randomized umbrella mishaps followed by the rain stopping before the umbrella succeeds.
- Click, tap, drag, button, and keyboard controls.
- Generated rain particles, puddle effects, weather audio, sound toggle, and reset control.
- Accessible status updates, visible focus, responsive behavior, and reduced-motion support.
- Dependency-free verification suite and production/security documentation.
